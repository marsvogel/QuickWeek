# Support

Need help with QuickWeek? Here is where to go:

- **Questions, bugs, and ideas** → open an [issue](https://github.com/marsvogel/QuickWeek/issues). Please check [existing issues](https://github.com/marsvogel/QuickWeek/issues?q=is%3Aissue) first.
- **Installation & first launch** (the Gatekeeper prompt on an unsigned app) → see the [README](README.md#installation).
- **Security vulnerabilities** → do not open a public issue; use [private reporting](https://github.com/marsvogel/QuickWeek/security/advisories/new) instead (see [SECURITY.md](SECURITY.md)).

QuickWeek is a single-maintainer hobby project, so responses are best-effort — but every issue is read.
